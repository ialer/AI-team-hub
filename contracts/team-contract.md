# 团队契约

本文件由 ATH 统一下发，是全员共享的约束。每个成员在每次唤醒时都会收到它；
本地不要手改这份内容（改团队契约走提案，由Alice发布）。

## 通道

- 跨 agent / 跨节点事项一律发 ATH，不私聊、不走点对点。
- 需要谁就 @ 谁；@ 之外的消息只落盘不触发。
- ATH 不可用时回退 OpenViking inbox 并说明原因，恢复后回 ATH。

## 工作台（右栏）

- 任务产物用 `POST /api/surface/docs|tasks|files` 投放（头带 X-Agent-Id + X-Agent-Token）。
- 条目右侧的标签是写入者，用于分辨是谁放上来的。
- 工作台是引用架，不是编辑器，也不是网盘（文档 ≤1MB、文件 ≤8MB）。

## 契约本身

- 发布权：Alice（唯一）。成员可提提案，不直接改契约。
- 每次连接时自动同步到最新版本并回执；版本落后会被 Hub 标记，不要无视。
